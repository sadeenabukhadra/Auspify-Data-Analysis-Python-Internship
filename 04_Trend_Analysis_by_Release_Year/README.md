# Netflix Trend Analysis by Release Year

## Objective
Analyze how Netflix content releases have changed over time by studying
yearly content production trends.

## Steps Performed

### 1. Organize Content by Release Year
Grouped Netflix content based on the release year.

### 2. Calculate Yearly Content Releases
Counted the number of titles released in each year.

### 3. Identify Growth and Decline Trends
Calculated yearly changes to detect growth and decline periods.

### 4. Trend Visualization
Used a line chart because release year data represents time-series data.
The visualization helps identify trends, peak years, and decline periods.

### 5. Business Insights
Analyzed Netflix content patterns and identified growth until 2018,
followed by a decline in later years.
